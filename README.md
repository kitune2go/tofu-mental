# すり潰されて豆腐メンタル

工場の夜勤ラインを、豆腐が定時（17:00）まで駆け抜ける3D横スクロールアクション。
プレス機に押され、飛んでくる言葉に削られ、足を踏み外せば石臼。崩れきる前に退勤を目指す。

## 遊び方

`index.html` をブラウザで開くだけで動きます（Three.js は CDN から読み込み）。
公開先：https://tofu-mental-seven.vercel.app/

| 操作 | キーボード | スマホ |
| --- | --- | --- |
| 移動 | ← → / A D | ◀ ▶ ボタン |
| ジャンプ（空中でもう一回） | Space / ↑ / W | ジャンプボタン |

## ステージ

- **1面 夜勤ライン**（`index.html`）：8:00〜17:00。プレス機・飛んでくる言葉・石臼。
- **2面 帰り道**（`stage2.html`）：17:00〜19:00。着信ドローン・崩れる足場・積み上がる用事（レンガ）・ドブ。小銭でメンタル少し回復。1面クリア時の残りメンタルを引き継げます。
- **EX 言い返し**（`fps.html`）：FPSモード。タップした場所に豆腐ブラスターを撃ち、迫る言葉と着信ドローンを撃ち落とす。60秒耐えると部長ドローン戦。
- **EX2 宇宙まで逃げた**（`space.html`）：宇宙シューティング。ドラッグで豆腐号を操縦（弾は自動）。タスク隕石・通知衛星をかわして月へ。60秒で本社衛星戦。
- **EX3 まな板の上**（`fight.html`）：格闘モード。包丁を持った板前ロボと1対1。ときどき見習いも走ってくる。体当たり・頭踏み・高野豆腐ガードで戦う。体力半分で板前が本気になり、千切り連打と包丁の雨が加わる。
- **EX4 北極**（`arctic.html`）：寒さで豆腐が凍っていく。生 → 凍結（鈍器）→ 解凍 → スポンジ。凍結中だけ氷の壁を割れてクマもはじけるが、薄氷は割れる。一度解けると二度と生には戻らない。メンタルは成長しない。

## ルール（1面）

- **メンタル**：減るほど豆腐が平たくなる（木綿 → 絹ごし → おぼろ → 崩れかけ）。0 で崩壊。
- **プレス機**：赤く点滅したら落ちてくる。挟まれると −35。
- **飛んでくる言葉**：当たると −20。
- **石臼**：隙間に落ちると、すり潰されて「おから」。
- **ベルトコンベア**：乗ると流される。
- **醤油・ネギ・生姜**：メンタル回復。
